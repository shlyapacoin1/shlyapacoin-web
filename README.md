# SHLYAPACOIN — frontend starter

Это демонстрационный фронтенд Mini App. Откройте `index.html` в браузере или разместите папку на HTTPS-хостинге.

## Сейчас реализовано
- Чёрно-золотой интерфейс SHLYAPACOIN.
- Тап по шляпе: +1 CROWN за тап.
- Энергия: 100 максимум, восстановление примерно 1 единица за 3 секунды.
- Улучшение: 10 000 CROWNS, увеличивает награду за тап на 1.
- Локальное сохранение демонстрационного прогресса в браузере.

## Важно перед запуском
Это только клиентский прототип. `localStorage` не защищён и не подходит для реальной экономики или начисления наград. Перед публичным запуском нужны сервер, база данных, проверка Telegram `initData`, серверная обработка тапов/энергии/покупок и настройка HTTPS Mini App в BotFather. Не вставляйте токен бота в клиентские файлы.
